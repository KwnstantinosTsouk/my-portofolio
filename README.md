# My First Portfolio Website 🚀

Καλώς ήρθατε στο πρώτο μου προσωπικό portfolio! Αυτό το project δημιουργήθηκε στο πλαίσιο της προσωπικής μου ανάπτυξης και της επένδυσης στις γνώσεις μου γύρω από την πληροφορική.

## 📌 Σχετικά με το Project
Αυτή η σελίδα είναι μια απλή, καθαρή και κομψή κάρτα παρουσίασης (profile card) που περιλαμβάνει:
- Μια σύντομη εισαγωγή για τις σπουδές μου στο **Χαροκόπειο Πανεπιστήμιο** (Τμήμα Πληροφορικής και Τηλεματικής).
- Άμεσους συνδέσμους (κουμπιά) για τα social media και το email μου.
- Σκοτεινό θέμα (Dark Mode) για ξεκούραστη ανάγνωση.

## 🛠️ Τεχνολογίες που Χρησιμοποιήθηκαν
- **HTML5** για τη δομή της σελίδας.
- **CSS3** για το στυλ, το Flexbox layout και τα εφέ (hover states).
- **Git & GitHub** για τη διαχείριση κώδικα και το hosting μέσω του GitHub Pages.

## 🎯 Ο Στόχος μου
Ως φοιτητής πληροφορικής, στόχος μου είναι να ξεφύγω από την παθητική κατανάλωση των social media, να δημιουργώ δικά μου projects, να αναπτύξω τις ικανότητές μου στο software development και να χτίσω το μέλλον μου στον κλάδο.
